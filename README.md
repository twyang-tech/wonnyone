# UA 소재 자동 네이밍 도구 — Phase 2

기존 Tkinter 화면과 네이밍 옵션을 유지하는 로컬 파일 처리 도구입니다.
Google Drive / Sheets 연동은 포함하지 않습니다.

## Windows 실행

```powershell
py -m pip install -r requirements.txt
# 선택 기능
py -m pip install tkinterdnd2 ttkbootstrap
py "UA-Naming.pyw"
```

Python 설치에 Tcl/Tk가 포함되어야 합니다. 영상 자동 분석은 PATH에 등록된
`ffprobe`가 필요합니다 (`ffprobe -version`으로 확인).
영상 분석이 실패하면 원인을 경고하고 사용자가 확인 후 진행할 수 있습니다.

## 사용 흐름

1. 기존 입력창에서 게임, 소재명, 언어, CTA, 날짜 및 저장 옵션을 설정합니다.
2. 파일 선택 또는 드래그앤드롭으로 파일을 추가합니다.
3. 하단 Preview에서 파일별 실제 유형·형식·해상도·최종 이름·저장 경로와 세트 상태를 확인합니다.
4. 실행 버튼을 누르면 전체 결과 Preview 확인창이 열립니다.
5. `확인 후 실행`을 누르면 파일 수·변경 예정 수·경고와 해상도 문제를 요약한 최종 확인 팝업이 열립니다.
   팝업에서 `실행`을 선택해야 파일이 변경됩니다. 기본 포커스는 `취소`이며, Tab으로 이동하고 Enter로 선택, Esc로 취소합니다.
   취소 또는 확인창 닫기는 파일을 변경하지 않습니다.

기본값은 원본을 보존하는 복사본 저장입니다. 원본 위치 처리 옵션은 추가 확인을 받으며,
이름이 변경되면 성공적으로 저장한 뒤 원본을 제거합니다.
이미지 저장은 임시 파일을 거쳐 적용해 변환 실패로 원본이 손상되는 것을 방지합니다.

## 세트와 이름 충돌

- 이미지 6종, 영상 3종을 게임·소재명·언어·미디어·CTA·날짜·출력 형식별로 묶습니다.
- 해상도는 실제 픽셀 크기로 검사하며 폴더를 나누지 않습니다.
- 누락·중복·예상 외 해상도 경고는 확인 후 진행할 수 있습니다.
- **기존 파일 또는 선택 파일끼리 최종 이름이 충돌하면 실행을 차단합니다.**
  기존 자동 `_1` 번호 추가는 사용하지 않습니다. 저장 폴더, 소재명 또는 이름 옵션을 조정해주세요.
- 중복 해상도 경고 자체는 진행 가능하지만, 중복 파일의 최종 이름까지 같으면 이름 충돌을 먼저 해결해야 합니다.
- 영상 비율 옵션을 모든 파일에 적용하면 서로 다른 해상도가 동일 이름을 만들 수 있습니다.
- `.jpeg`의 `JPEG_` 접두사, 영상 CTA, 길이·비율 옵션은 기존 네이밍 호환성을 위해 유지합니다.
- 원본 이름 유지 모드는 입력한 메타데이터를 기준으로 세트를 묶습니다.
  서로 다른 소재나 언어는 별도 작업으로 선택해주세요. 기존 파일명에서 메타데이터를 추측하지 않습니다.

## 설정과 구조

`config.json`에서 게임·언어·이미지/영상 기대 해상도를 변경할 수 있습니다.
현재 파일명 포맷·압축·비율 옵션은 호환성을 위해 네이밍 모듈에 유지합니다.

- `UA-Naming.pyw`: Windows 실행 진입점 (기존 UI를 실행)
- `UA-Naming .py`: 기존 UI와 진입점, 파일별 Preview 및 최종 확인
- `ua_naming/media.py`: 파일 형식·해상도 분석 및 캐시
- `ua_naming/naming.py`: 기존 네이밍 함수·옵션
- `ua_naming/image_io.py`: 기존 포맷 변환·압축
- `ua_naming/planning.py`: 소재 세트 검증, 읽기 전용 계획, 충돌 검사, 안전한 실행
- `ua_naming/settings.py`: 설정 로드·검증
- `ua_naming/dialogs.py`: 키보드 접근성을 지원하는 최종 확인 팝업

## 검증

```powershell
py -m unittest discover -s tests -v
```

테스트의 영상 생성에는 `ffmpeg`도 필요합니다. 앱은 영상 분석에 `ffprobe`만 사용합니다.
GUI는 Windows에서 직접 확인해야 합니다. 많은 영상의 첫 Preview 분석과 실행 중에는
처리가 완료될 때까지 화면 응답이 지연될 수 있습니다.
